# SMARMELLOPOLY 🧃

Gioco da tavolo di città italiane per 2-6 giocatori. Il tabellone va sulla TV, ognuno gioca dal proprio telefono, da qualsiasi connessione e senza account.

- `index.html`: il gioco
- `config.js`: indirizzo e chiave pubblica del progetto Supabase "smarmellopoly"
- `supabase-setup.sql`: tabelle e permessi del database (già applicati)
- `supabase.js`, `591.supabase.js`, `qrcode.js`: librerie incluse, nessuna installazione necessaria

Sito statico: Vercel lo pubblica così com'è, senza configurazione.
